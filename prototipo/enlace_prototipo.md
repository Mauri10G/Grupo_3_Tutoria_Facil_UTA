## Flujo navegable

Inicio → Reservar nueva tutoría → Elegir docente → Ver horarios disponibles → elegir jueves y un horario → Continuar con este horario → marcar confirmación → Confirmar reserva → Reserva confirmada → Reprogramar.

## Tarea de prueba

Reservar una tutoría para el jueves y luego cambiar el horario.
